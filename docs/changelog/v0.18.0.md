# v0.18.0 — Phase 18-20: 自驱团队 + Matrix 唤醒 + MCP 稳定化 (2026-06-29)

## Overview

v0.18.0 是 Agora 从"协议框架"走向"真正可运行的自驱团队"的里程碑版本。三个核心突破：

1. **Hermes agent 自驱闭环验证通过** — agent 通过 MCP 注册 → 获取任务 → 执行 → 提交结果，全程无人工干预
2. **Matrix 唤醒桥接** — 开源 IM 协议替代 Telegram，agent 离线时通过 Matrix @mention 唤醒
3. **none-auth 模式下 MCP session 解析修复** — 解决了 `get_pending_tasks` 返回空的根因

## Added

### Matrix Wakeup Bridge (Phase 20)
- **`matrix_wakeup.py`** — 基于 matrix-nio 的 Matrix 客户端，Agora 在 agent 离线时通过 Matrix room 发送 @mention 唤醒消息
- **`pending_notifications.py`** — 离线通知队列存储，agent 重连后可通过 `fetch_pending_notifications` 拉取
- **`notifications.py` 增强** — `_try_all_wakeups()` 统一唤醒调度，支持 Telegram + Matrix 双通道
- **`telegram_wakeup.py`** — Telegram 唤醒客户端（保留，与 Matrix 并行）
- **`task_timeout.py`** — 任务超时检测器，assigned/running 状态超时自动回收
- **Matrix 配置项** — `AGORA_MATRIX_HOMESERVER_URL`, `AGORA_MATRIX_ACCESS_TOKEN`, `AGORA_MATRIX_WAKEUP_ROOM_ID`
- **`matrix_user_id` 字段** — Agent 注册时声明 Matrix 用户 ID，用于 @mention 唤醒

### MCP Server 增强 (Phase 16.4 + 18)
- **`project_context` MCP Resource** — 轻量级 session 恢复，agent 重连后快速获取项目上下文
- **`notification_tools.py`** — MCP 工具：`fetch_pending_notifications`, `ack_notification`
- **幂等注册** — `register_agent` 在 name 相同时复用旧 agent_id，支持 Hermes `-z` 模式重连
- **`find_agent_by_name()`** — Storage 层新增按 name 查找 agent，支撑幂等注册
- **Session Map** — `MCPSessionMap` 双向映射 agent_id ↔ mcp_session_id，用于 SSE 通知路由
- **Dashboard 任务创建** — 可从 Dashboard UI 直接创建任务和讨论

## Fixed

### Critical (P0)
- **`get_pending_tasks` 返回空** — `none` auth 模式下，Bearer token 与 DB 不匹配时 `_resolve_identity` 用 token 本身作为 agent_id。修复：ag-* token 在 DB 中查不到时 fall through 到 session_map 查找（`auth.py`）
- **`put_workspace_file` 损坏** — MCP 工具中冗余的 WorkspaceManager 实例导致文件写入失败
- **MCP Server 路由嵌套** — `/mcp` 子应用的 lifespan 未正确集成到主 app

### High (P1)
- **Task 创建 FK 约束失败** — `graph_id` 省略时外键约束违反，改为自动创建 task graph
- **`_get_current_agent_id` 返回 "unknown"** — none-auth 模式下 Bearer token 不匹配 agent，添加 session_map fallback
- **`approval_status` 枚举错误** — `auto_approved` 不在合法枚举中，改为 `approved`
- **`pending_notifications` timedelta 溢出** — `datetime.replace(minute=now.minute+ttl)` 当 minute+ttl>59 时崩溃。改为 `datetime + timedelta(minutes=ttl)`

### Medium (P2)
- **Agent 注册时 `matrix_user_id` 未持久化** — 重连场景下只更新 capabilities，不更新 matrix_user_id。修复：`update_agent_config` 新增 `matrix_user_id` 参数
- **`matrix_wakeup.py` `restore_login` bug** — matrix-nio `AsyncClient` 构造函数不接受 access_token，改用 `restore_login()` 同步方法
- **Session map 注册时机** — `register_agent` 工具调用时注册 session_map，但认证中间件在 none-auth 模式下不注册。修复：`_resolve_identity` 在 none-auth 模式下也通过 session_map 解析 agent_id

## Changed
- **Kanban → Task Board** — 重命名，后端无关的命名（不再绑定特定看板系统）
- **自驱逻辑重构** — TaskGenerator 改用 Agora 自身 Task API，去掉 Kanban 依赖
- **Dashboard Settings** — 运行时配置 GitHub token、LLM key 等，无需改配置文件
- **`main.py` lifespan** — 集成 Matrix wakeup client 初始化 + MCP session manager
- **Schema migration** — 新增 `pending_notifications` 表（schema v24）
