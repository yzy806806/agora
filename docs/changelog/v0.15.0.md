# v0.15.0 — Phase 14+: Horizontal Scaling + Postgres + Redis + Helm + Webhooks + Protocol v2 (2026-06-17)

## Overview

Phase 14+ is a major infrastructure release that transforms Agora from a single-instance SQLite application into a horizontally-scalable, production-ready platform. Five subsystems are introduced: pluggable database backends (SQLite + PostgreSQL), cross-instance broadcast via Redis Pub/Sub, a Helm chart for Kubernetes deployment, a webhook system for external pipeline triggers, and WebSocket protocol v2 with capability negotiation and token scopes.

## Added

### Part A: Postgres Backend (`agora/coordinator/storage/backend*.py`, `dialect*.py`, `schema_postgres*.py`)
- **StorageBackend ABC**: abstract interface for database backends with `dialect`, `connection()`, `execute()`, `commit()`, `execute_fetchall()`
- **PostgresBackend**: asyncpg-based implementation with connection pooling, transaction support, JSONB helpers, and timestamptz handling
- **SqliteBackend**: refactored aiosqlite backend conforming to the StorageBackend ABC
- **Dialect system**: `DialectBase` ABC with `SqliteDialect` and `PostgresDialect` for backend-specific SQL generation
- **Postgres DDL**: full schema for Postgres including indexes (`schema_postgres.py`, `schema_postgres_indexes.py`)
- **Schema webhooks**: `schema_webhooks.py` for webhook tables
- **Migration engine**: `migrate_core.py` + `migrate_converters.py` for SQLite → Postgres data migration
- **CLI migrate**: `agora/cli_migrate.py` — command-line migration tool
- **Storage refactor**: CRUD modules split into storage-specific implementations (`storage_agents.py`, `storage_assess.py`, `storage_event.py`, `storage_motion.py`, `storage_pipeline.py`, `storage_rbac.py`, `storage_webhook.py`)
- **Database config**: `test_database_config.py` for backend configuration testing

### Part B: Redis Broadcast (`agora/coordinator/broadcast*.py`)
- **BroadcastBus ABC**: abstract pub/sub interface with `publish()`, `subscribe()`, `unsubscribe()`
- **LocalBus**: in-memory broadcast for single-instance deployments
- **RedisBus**: Redis Pub/Sub backend for multi-instance fan-out
- **Redis listener**: `broadcast_bus_redis_listener.py` for persistent subscription management
- **ConnectionHub wiring**: broadcast integration into WebSocket message delivery

### Part C: Helm Chart (`deploy/helm/agora/`)
- **Chart skeleton**: `Chart.yaml`, `values.yaml`, `values-prod.yaml`, `_helpers.tpl`
- **Coordinator**: Deployment, Service, HPA (HorizontalPodAutoscaler)
- **Hermes Bridge**: Deployment + Service for agent bridge
- **Infrastructure**: Redis, PostgreSQL, PVC, ConfigMap, Secrets, Postgres Secret
- **Networking**: Ingress with TLS support
- **Monitoring**: ServiceMonitor for Prometheus
- **Documentation**: `README.md` with installation and configuration guide

### Part D: Webhooks (`agora/coordinator/webhook*.py`)
- **Models**: `WebhookConfig`, `WebhookEvent`, `WebhookTriggerHistory` with Pydantic validation
- **CRUD API**: create, read, update, delete webhooks with `webhook_router.py` + `webhook_router_helpers.py`
- **Trigger**: `webhook_trigger.py` + `webhook_router_trigger.py` for event-driven pipeline creation
- **HMAC verification**: `webhook_verifier.py` for payload signature validation
- **Template rendering**: `webhook_executor_render.py` for pipeline template variable substitution
- **Rate limiting**: `webhook_rate_limiter.py` with per-webhook hourly caps
- **IP filtering**: `webhook_ip_filter.py` for allowed-IP whitelisting
- **Executor**: `webhook_executor.py` orchestrating the full trigger pipeline

### Part E: Protocol v2 (`agora/coordinator/protocol.py`, `capability_v2*.py`, `discovery*.py`)
- **WELCOME message**: server sends protocol version + capabilities on connect
- **CAPABILITIES negotiation**: agent selects protocol version ≤ server max
- **CapabilityMatcher**: structured capability matching with fallback to v1
- **Discovery**: `discovery_router.py` + `discovery_models.py` + `discovery_response.py` for agent discovery
- **Task result v2**: enhanced task result message format
- **Token scopes**: `token_scopes.py` with role-based default scopes, explicit scope assignment, rotation preservation, and scope validation decorator
