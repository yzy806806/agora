# v0.14.0 — Phase 14: Shared Workspace (2026-06-16)

## Overview

Phase 14 introduces a **multi-tenant shared workspace** with pluggable storage backends (local filesystem + S3), distributed lock management, bulk operations, and real-time WebSocket synchronization for multi-client collaboration.

## Added

### Workspace Manager (`agora/coordinator/workspace/`)
- **Multi-backend architecture**: local filesystem and AWS S3 backends with unified interface
- **Lock manager**: TTL-based file locking with automatic expiry and refresh
- **Bulk operations**: batch directory listing, batch file CRUD
- **Directory operations**: recursive listing, tree structure, path traversal
- **WebSocket sync**: real-time file change notifications across clients
- **RBAC integration**: workspace-level access control with permission checks

### Workspace Routers
- `workspace_router`: core file read/write/delete endpoints
- `workspace_router_bulk`: bulk file and directory operations
- `workspace_router_dirs`: directory listing, tree, and traversal
- `workspace_router_locks`: lock acquire/release/refresh/list
- `workspace_router_read`: file read with range support
- WebSocket endpoint for real-time sync messages

### Pipeline Integration
- `pipeline_workspace.py`: workspace-aware pipeline execution
- `pipeline_workspace_review.py`: workspace review integration
- Workspace models for pipeline context

### Documentation
- `docs/API-phase14-workspace.md`: comprehensive API reference for all workspace endpoints

### Tests
- 30 new test files covering: backends (local + S3), lock manager, bulk ops, WebSocket, router, RBAC, migration, pipeline integration
- Total: 1264 tests pass (all unit tests, integration tests require running coordinator)

## Changed

- **Dependencies**: added `aiobotocore>=2.12` for S3 backend support
- `rbac.py`: workspace permission checks
- `storage/schema.py`: workspace tables
